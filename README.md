# Maquetado Responsivo con Bootstrap 5

## Descripción

Proyecto académico desarrollado con HTML5 y Bootstrap 5 para practicar diseño responsivo mediante componentes y utilidades del framework.

## Tecnologías

* HTML5
* Bootstrap 5.3.2
* CSS
* JavaScript (Bootstrap Bundle)

## Componentes implementados

* Navbar responsiva
* Carousel de imágenes
* Sistema Grid (Container, Row y Columns)
* Galería de imágenes responsiva
* Footer con Flexbox

## Conceptos aplicados

* Diseño responsivo
* Sistema de 12 columnas de Bootstrap
* Clases utilitarias para espaciado y alineación
* Componentes predefinidos de Bootstrap
* Integración mediante CDN
